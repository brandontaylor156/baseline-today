# Baseline Today

ATP and WTA rankings, player pages, search and favorites, with live scores to come.

Built with Next.js (App Router), TypeScript, Tailwind, Supabase and Vercel. A rebuild of the
original Flask app (2022). Work in progress: see [PLAN.md](PLAN.md).

## Development

```bash
npm install
npm run dev
```

Checks (also run in CI): `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.
